# Module 6: Text Clustering and Topic Modeling

This module introduces text clustering and topic interpretation with BERTopic
using 1,398 HuffPost articles from 2022.

## Contents

| File | Description |
| --- | --- |
| [`DSA495-M06-Topic-Modeling.ipynb`](./DSA495-M06-Topic-Modeling.ipynb) | In-class activity covering document embeddings, UMAP, HDBSCAN, c-TF-IDF, topic visualizations, and outlier analysis. |

## What You Will Do

- Create sentence embeddings for news articles.
- Build and interpret a BERTopic model.
- Examine topic words, representative articles, and document clusters.
- Explore an intertopic distance map and topic hierarchy.
- Inspect outliers and export document-level topic results.

## Before You Begin

Google Colab is recommended. Make sure `news_category_2022.csv` is available in
Google Drive and update `DATA_PATH` if needed. Internet access is required to
install the packages and download the embedding model.
