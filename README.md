# DSA 495: Text Analysis for Data Science

**Fall 2026 · NC State University**

This repository contains notebooks, code, data resources, and project templates
for [DSA 495: Text Analysis for Data Science](https://courseweb.site/dsa495-2026/).

This is a hands-on course on building and evaluating LLM-based systems for text
data in Python. Topics include embeddings, classification, clustering, context
design, evaluation, retrieval-augmented generation (RAG), tool use, agentic
workflows, and model adaptation.

## Repository Contents

- `ModuleXX/` — one folder per course module, containing notebooks, examples,
  and supporting resources (beginning with [`Module01/`](./Module01/)). Module
  folders will be added and updated as the course progresses.
- [`Project/README.md`](./Project/README.md) — Topic Brief template for student
  project teams.

For the sequence of topics and assigned resources, see the course
[schedule](https://courseweb.site/dsa495-2026/schedule.html) and
[materials](https://courseweb.site/dsa495-2026/materials.html) pages.

## Course Tools

The course primarily uses Python, Google Colab, GitHub, and Hugging Face.
