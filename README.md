# DSA 495: Text Analysis for Data Science

**Fall 2026 · NC State University**

This repository contains course materials, code, data resources, and project templates for DSA 495: Text Analysis for Data Science.

The course introduces practical and reproducible workflows for working with text data in Python. Topics include text preparation, embeddings, classification, clustering and topic modeling, semantic search, retrieval-augmented generation, evaluation, and introductory model adaptation.

## Repository Contents

- `project/README.md` — Topic Brief template for student project teams
- Additional notebooks, code, and resources will be added throughout the semester.

## Course Tools

The course primarily uses Python, Google Colab, GitHub, and Hugging Face.
