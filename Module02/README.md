# Module 2: Language Models, Tokens, and Embeddings

This module explores how language models represent text, moving from generated text and token IDs to contextual, sentence, and item embeddings.

## Contents

| File | Description |
| --- | --- |
| [`DSA495-M02-Tokens-Embeddings.ipynb`](./DSA495-M02-Tokens-Embeddings.ipynb) | In-class lab covering text generation, tokenizers, transformer embeddings, cosine similarity, and playlist-based song embeddings. |

## What You Will Do

- Generate text with an instruction-tuned language model and inspect its token IDs.
- Compare how several tokenizers split the same text.
- Examine contextual token embeddings from a transformer encoder.
- Compare complete texts using sentence embeddings and cosine similarity.
- Explore how playlist co-occurrence can be used to learn song embeddings.

## Before You Begin

Google Colab is recommended. Internet access is required the first time pretrained models are downloaded, and a GPU runtime is recommended for the Phi-3 generation examples. Follow the notebook in order and complete each checkpoint before continuing.
